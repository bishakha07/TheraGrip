# TheraGrip
TheraGrip — AI-assisted grip-training and rehabilitation measurement device (design stage).

Design-Stage Project | Vishwakarma Awards 2026

1. Project Overview

TheraGrip is a proposed instrumented grip-training and rehabilitation measurement device designed to measure grip force and support grip-training activities through sensor-based feedback.

The project was initially proposed during Stage 1. It is currently in the design phase, where the system architecture, proposed components, circuit concept, and development roadmap are being documented.

2. Problem Statement

Measuring grip strength and tracking grip-training progress can be challenging without an appropriate measurement device. TheraGrip proposes a sensor-based approach to explore grip-force measurement and feedback.

3. Proposed Solution

The proposed device aims to:

- Measure grip force using force-sensitive sensors.
- Process sensor readings using a microcontroller.
- Explore feedback through visual indicators and vibration.
- Support future calibration and validation of measurements.

These are planned features and have not yet been implemented or validated.

4. Proposed Technology and Components

- Microcontroller: ESP32-S3 development board
- Sensors: Force-sensitive resistors (FSRs)
- Signal acquisition: ADS1115 analog-to-digital converter module
- Motion sensing: IMU sensor
- Feedback: RGB LEDs and vibration motor
- Power: Rechargeable battery and appropriate charging/protection circuitry

The final component selection and circuit compatibility still require verification.
